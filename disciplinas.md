# Descrevendo as disciplinas do curso!
## 
# - Criatividade e inovação 
#
#
## A disciplina de Criatividade e Inovação explora o nexo entre o pensamento disruptivo e a resolução técnica de problemas. No contexto da Engenharia de Software, ela foca em desconstruir padrões mentais rígidos para viabilizar a criação de soluções tecnológicas que não sejam apenas funcionais, mas que entreguem valor real e resolvam dores latentes dos usuários.
#
#
# - Lógica computacional
## A disciplina de Lógica Computacional é o alicerce fundamental para o desenvolvimento de software. Ela estuda as estruturas de raciocínio formal e as regras matemáticas que permitem traduzir problemas do mundo real em sequências de instruções lógicas que um processador pode executar com precisão.
#
#
# - Fundamentos para engenharia de software
## A disciplina de Fundamentos de Engenharia de Software introduz os conceitos, métodos e ferramentas essenciais para a produção de sistemas de alta qualidade. Ela aborda o software não apenas como código, mas como um produto de engenharia que exige planejamento, manutenção, escalabilidade e processos bem definidos para ser bem-sucedido.
#
#
# - Programação e sistemas computacionais
## A disciplina de Programação e Sistemas Computacionais conecta a teoria dos algoritmos com a execução prática em arquiteturas de hardware. Ela foca no aprendizado de linguagens de programação (como C, Python ou Java) e na compreensão de como o Sistema Operacional gerencia recursos como memória, processamento e armazenamento para executar o código de forma eficiente.
